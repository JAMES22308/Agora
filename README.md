## About Agora

Agora is a multi-business e-commerce platform where multiple businesses can manage their own accounts, sellers, buyers and products.

### User Roles

- **Agora Admin:** Platform-level administration.
- **Business Admin:** Manages their business profile, sellers and buyers.
- **Seller:** Manages their profile and own products.
- **Buyer:** Browses products from all businesses, purchases products and views order history.

## Running the Application

1. Start Apache and MySQL.
2. Make sure the `agora` database has been imported.
3. Open the application using the local URL above.
4. Log in using one of the test accounts.
